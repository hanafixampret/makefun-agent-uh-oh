One word an agent says when it has no idea what to do: **404**.

The machine's own confession — not found. No caption, no excuse, just the
error code an agent blurts when it is completely lost. It lands instantly,
sounds like a machine caught mid-task, and it is fresher than the obvious
"uh-oh" everyone types first.

`main.ts` writes the entry to `/output/entry.txt` (1–99 characters, single word).
